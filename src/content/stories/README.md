# Stories

Each `.md` file in this folder is one story, normally created and edited
through Pages CMS (see `docs/CONTENT-EDITOR-GUIDE.md`).

- The filename becomes the web address: `my-story.md` → `/stories/my-story/`.
- Stories with `draft: true` are never built or published.
- Images live in `src/assets/stories/`.

This README is ignored by the site and by the CMS.
