# Partners

Each `.yml` file in this folder is one partner business that gives Cork
Vegans members a discount. They're normally added and edited in Pages CMS
("Partners"; see `docs/ADMIN-GUIDE.md`) and shown on the Membership page.

- Partners with `hidden: true` aren't shown.
- Logos live in `src/assets/partners/`.

This README is ignored by the site and by the CMS.
