# Sample stories

Example stories so you can see how the Stories pages look while there is no
real content yet. They show up in `npm run dev` and local builds, but the
live deploy sets `CV_HIDE_SAMPLES=1`, so **they never appear on
corkvegans.ie**. They are not shown in Pages CMS either.

Delete this folder (and `src/assets/sample-stories/`) once real stories have
been published.
